Dodaj do swojego AI

claude.ai i Claude Desktop

  1. Otwórz Customize › Connectors i wybierz Add › Add custom connector.
  2. Nazwij go NoBrainer Tech Flow i wklej adres:
https://mcp.nobrainer.tech/mcp
  1. Wybierz No sign-in, potem Add. W czacie włączysz go przez + › Connectors.

Team i Enterprise: najpierw Owner dodaje go w Organization settings › Connectors.

ChatGPT

  1. Otwórz ChatGPT Plugins, wybierz + › Add custom MCP server.
  2. Nazwij go NoBrainer Tech Flow i wklej adres w polu Connection:
https://mcp.nobrainer.tech/mcp
  1. Wybierz brak uwierzytelniania, zaakceptuj ostrzeżenie i kliknij Create as a plugin.

Narzędzia

  • start_flow_task

    Sprawdza cel i definicję ukończenia; zwraca identyfikatory punktów i podpisany token kontraktu.

  • get_flow_step

    Do sześciu reguł dla jednego etapu, zdarzenia lub modułu Flow, cytowanych z przypiętego wydania Flow.

  • check_flow_evidence

    Sprawdza wyniki testów i poleceń, hashe plików i status adresów URL dla każdego punktu.

  • check_flow_done

    DONE tylko wtedy, gdy każdy punkt ma zaakceptowany, aktualny dowód.

  • draft_flow_handoff

    Szkielet raportu końcowego na podstawie potwierdzenia ukończenia.

  • recommend_flow_model

    Krótka lista 3 modeli z przypiętego zrzutu benchmarku NoBrainer AI.

Uczciwe ograniczenia

Serwer nie widzi twojego komputera. Dowody zgłasza agent; serwer sprawdza ich spójność, nie prawdziwość.
