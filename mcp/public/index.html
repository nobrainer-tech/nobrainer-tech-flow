NoBrainer Tech Flow MCP server

One task contract, one evidence check and one done gate for AI agents, the same in every MCP client. Free, stateless: no accounts, no stored task content, no AI model.

Endpoint https://mcp.nobrainer.tech/mcp (Streamable HTTP, no sign-in)

Tools

  • start_flow_task: check the outcome and definition of done; get item IDs and a signed contract token.
  • get_flow_step: up to six rules for one Flow stage, event or module, quoted from the pinned Flow release.
  • check_flow_evidence: check test output, command results, file hashes and URL status against each item.
  • check_flow_done: DONE only when every item has accepted, current evidence.
  • draft_flow_handoff: a final-report skeleton from the done receipt.
  • recommend_flow_model: a top-3 model shortlist from a pinned snapshot of the NoBrainer AI benchmark.

Install

claude mcp add --transport http nobrainer-tech-flow https://mcp.nobrainer.tech/mcp
# ~/.codex/config.toml
[mcp_servers.nobrainer-tech-flow]
url = "https://mcp.nobrainer.tech/mcp"

Other clients: install snippets.

Honest limits

The server cannot see your machine. Evidence is reported by the agent; the server checks consistency, not truth.
