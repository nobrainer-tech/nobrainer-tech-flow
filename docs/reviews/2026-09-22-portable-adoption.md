# Portable behaviors adopted after the top-ten review

The first review mapped documented capabilities but did not implement every
useful portable gap. This follow-up inspected actual upstream skills and source,
then added three original contracts to existing Flow owners. It neither copies
upstream prompts nor claims Flow implements their specialist runtimes.

| Source and inspected revision | Portable gap | Change in Flow |

| [Agentic Awesome Skills](https://github.com/sickn33/agentic-awesome-skills/tree/12123b491916cbde2811e2a6b3855a3839298a1c) | A selected skill name does not show whether all required capabilities were covered | Team now records applicable needs, checked/unknown/gap states, selected/rejected identities, and source/ref/hash evidence for durable selections |

Small tasks keep the quick path. No fixed list of specialists, new approval
round, external install, catalog service or second model is required. Configured
Jev/Laya can suggest rankings; they cannot claim coverage, grant permission or
promote a result. Source changes invalidate the evidence for a reused selection.

## Explicit boundaries

Superpowers' planning/debugging/review principles and Ponytail's minimal-change
ladder already have Flow owners. Caveman and I Have ADHD overlap on clear,
action-first prose; their transport proxies and persistent output modes are not
implicitly included. Graphify and Understand Anything provide graph machinery,
K-Dense provides scientific domain tools, and Diagram Design provides dedicated
visual tools. Team can select those capabilities when appropriate; instructions
are not equivalent to implementing their engines.

Verification separates source-contract scenario review, deterministic regressions,
client behavior and public delivery. No empirical head-to-head superiority or
universal speedup is asserted. The ten nbak comparison pages explain both sides'
actual mechanisms and when each fits the task.
