## Selected release change

The useful new core boundary is optional typed-decision support with remembered
configuration, not a larger mandatory portfolio. Jev remote and Laya local are
profiles of the same workflow, default off. Single-model and tool-limited users
retain the complete lifecycle. Suggestions cannot approve actions or completion.

Other upstream opportunities remain discoverable through Team. Exact source/ref,
selected capability, evidence, permissions and rollback should be retained with
the existing task plan when acquisition is needed. No general catalog service,
graph engine or social crawler is required to use Flow.

## Evidence and limits

The new helper passed synthetic live Noul calls through direct Jev 1.13.0 and
offline cached Laya multilingual on Apple Silicon. This proves only those calls.
Nine focused tests cover preference persistence, off/data gates, attempt limits,
timeout fallback, malformed distributions and output field filtering. The full
candidate regression currently passes 198 tests. New changes invalidate affected
evidence and must be rechecked before release.

No cross-harness speedup, native language quality or universal model compatibility
is inferred. Clean-client routing and the remaining typed primitives require
their own current readbacks. Release/website/X publication are separate gates.
