## Scope

- The existing `nobrainer-sessions` portfolio now ships the adaptive
  `session-restart` protocol and its deterministic Python decision helper. The
  protocol requires a durable checkpoint, exact identity, verified takeover and
  controlled retirement before the source session is archived. It does not add a
  sixteenth skill, watcher daemon, scheduler, global hook or native session API.
- The source-backed OpenAI Codex refinements already present in the base are
  included: bound restart context fragments, preserve reusable input order and
  bytes where a host supports reuse, bind review monitoring to the exact head,
  exclude pending draft feedback, keep retries finite and diagnosed, and select
  only review perspectives justified by the changed boundary. The adoption map
  remains source-contract evidence,
  not model-quality, token-cost or provider-runtime evidence.
- Active package and adapter metadata is consistently `1.8.0` across the npm
  package, lockfile, root plugin, Claude, Codex, Cursor, Kimi, Gemini and
  marketplace manifests. The fifteen canonical skills, package/plugin IDs and
  client-neutral adapter paths remain unchanged.
- The active README, release notes, compatibility statement and session-restart
  guide now describe the v1.8.0 source and keep the published v1.7.1 source as
  the rollback anchor. Dated v1.7.1 release, publication, review and evaluation
  records retain their original bytes.
