# v1.14.0 - optional Jev and Laya decisions

Same seventeen-skill workflow, with an optional
typed-decision layer. Core runs with the host-selected model and no provider
calls. Setup remembers core/Jev/Laya, and explicit settings can change it later.
Remote Jev and cached local Laya return advisory suggestions with timeout,
attempt-limit and malformed-response fallback. They cannot execute actions or
approve completion.

The [top-ten review](../reviews/2026-09-22-top10-and-optional-decisions.md)
maps existing coverage and identifies optional graph, scientific and research
capabilities without importing a second workflow or requiring a skill catalog.

## Rollback

Set decision mode off or provider core to disable optional calls. Reinstall
the verified v1.13.0 source if the release itself needs rollback; preserve
project instructions and unrelated changes. Website preimages must be retained
before deployment. GitHub release, public website and X permalink require their
own publication readback; CI does not prove those external states.
