# Version 1.9.0 - decision depth and feasibility gates

This release adds one canonical decision skill contract with three explicit
depths while preserving the fifteen-skill portfolio and existing technical
package identities.

## Scope

- `just decide` and `just-decide` select a short LIGHT decision.
- `decide`, `nb-decide` and `nobrainer-decide` select STANDARD analysis.
- `deep decide` and `deep-decide` select HIGH analysis.
- Ranking first checks feasibility, deadline, budget and minimum observable
  reliability. It then compares total cost, time to useful output, growth,
  reversibility and evidence-backed robustness or antifragility.
- Panels, model changes and artificial score gaps are optional. A missing
  decisive fact produces a bounded experiment or explicit unknown.

## Verification boundary

The release candidate passed both skill validators, the deterministic package
suite, dedicated decision-contract tests, syntax checks, whitespace checks and a
staged secret scan. A three-case MAIN holdout exercised the LIGHT, STANDARD and
HIGH invocation routes and checked the expected output constraints.

These checks validate the portable instruction contract. They do not prove
automatic discovery in every client, model quality, decision quality in live
production or any financial outcome.

## Rollback

The rollback anchor is the published `v1.8.1` tag. Revert to that exact source
after verifying the tag and rerun its validators. Existing package/plugin IDs,
skill paths and compatibility aliases remain unchanged.
