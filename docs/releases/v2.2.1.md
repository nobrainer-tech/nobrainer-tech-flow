# v2.2.1: install Flow from npm and use the skills plugin

This release adds distribution paths without adding modules or a task-execution service. The eighteen skill bodies remain unchanged from v2.2.0.

- npm provides a named command to preview, apply and undo the existing client setup. Application retains a verified copy of release files at a stable profile path, so npx cache removal does not break installed links. Python 3.11+ is required for installation; help/version need only Node.
- A hook-free plugin ZIP contains the same skills, references and helpers, portable identity, OpenAI presentation metadata and Claude compatibility metadata.
- ChatGPT/Codex and Claude support skills plugins. Available tools and permissions remain the client's responsibility. Directory approval and client runtime acceptance are separate from package validation.

See [installation](../INSTALL.md) for npm commands, [native plugins](../CHAT_PLUGINS.md) for supported surfaces and [privacy](../PRIVACY.md) for the package's data boundary.

Verification records must distinguish packed-tarball installation, ZIP content checks, repository regression, npm publication and directory/client readback. A ZIP or a published npm tarball alone does not prove task performance in every client.
