# v1.12.0 - goal-driven delivery

This release adds GDD as an execution pattern inside the existing sixteen-skill
portfolio. The [specification](../specs/goal-driven-delivery.spec.md) defines full
outcomes, milestone acceptance, visible TODO, BUDDY authorization, operational
obstacle resolution and coordinated native workers. No separate GDD skill,
daemon or global permission override is introduced.

Codex workers use the documented Luna/max preset when supported and not overridden
by the owner. MAIN retains its selected model. Other clients retain portable
model policy. Parallelism is limited by ready independent work, native capacity
and 15 live descendants, with uncertain spawns reserving capacity and write scope.

Maintained display copy is `nobrainer-tech-flow`. Existing package IDs, paths,
aliases and historical evidence remain intact.

## Verification boundary

The release requires both source validators, the full deterministic suite,
source secret scan and bounded independent scenario review. These demonstrate
source contracts and evaluated scenario responses; they do not establish faster
completion or reliable unattended execution across all models and clients.
Actual deployment UI, physical MFA, host-only START and account quotas remain
subject to each host's capabilities and authority.

## Recovery

Rollback source is v1.11.0. Restore a verified source in an isolated checkout,
preserve unrelated working changes and read back installed links. No consumer
production or global configuration migration is part of this source release.
