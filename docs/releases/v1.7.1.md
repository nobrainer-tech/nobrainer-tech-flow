# Version 1.7.1 — NoBrainer Tech Flow

**From task to done.** Tell it what you need. Flow clarifies the goal, does the
work, and checks the result.

This is a product naming and documentation release. Maintained display labels
use **NoBrainer Tech Flow**, repository links use
[`nobrainer-tech/nobrainer-tech-flow`](https://github.com/nobrainer-tech/nobrainer-tech-flow),
and the product website is [nobrainer.tech/flow](https://nobrainer.tech/flow/).

Package and plugin identities remain `nobrainer-tech-skills`; marketplace IDs,
all fifteen skill names, `nb-ultra`, adapter module paths and installer targets
are preserved. The [migration guide](../MIGRATION_TO_FLOW.md) records each exact
identifier and how to update an existing source without adding a duplicate
installation.

## Verification scope

The skill bodies, client adapter code and bounded command runner are unchanged
from [v1.7.0](v1.7.0.md). Their existing evidence remains scoped to the tested
source and host. Historical release, review, specification and evaluation files
retain their original bytes and provenance.

Both skill validators and all **140 deterministic tests passed locally**,
including the source check without Git metadata. Readback confirmed consistent
1.7.1 manifests, preserved installation identities, identical 200-line AGENTS
and CLAUDE instructions, unchanged runtime and historical files, and a passing
whitespace check and scoped secret scan. Commit CI and publication readback remain separate;
this document alone is not proof of publication, repository redirection or a
client update.

The workflow diagram still describes the unchanged `nobrainer-ultra` behavior;
no new workflow diagram or runtime probe is required by this naming change.

The completed local run passed **140/140 tests** and both validators. The
Trending reconciliation records
435 screened discoveries, resolved metadata gaps and the expanded public
comparison coverage; it is not an external-runtime benchmark.

## Publication and recovery

The [GitHub release](https://github.com/nobrainer-tech/nobrainer-tech-flow/releases/tag/v1.7.1)
and its reviewed tag commit establish source publication after release. Website
deployment and the old repository/site redirects require separate live readback.
No marketplace, model-performance or token-cost claim follows from the rename.

Before updating, retain the installed source pin and any local configuration.
To roll back, use the prior reviewed source with the same technical package and
skill IDs; do not delete unrelated installations or change their paths.
