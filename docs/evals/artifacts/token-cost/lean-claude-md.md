## Token budget
- Run noisy commands so only failures reach you: quiet flags, or `2>&1 | tail -n 60`; grep a log before reading it.
- Locate with grep or glob first, then read only the lines you need.
- Hand broad searching and reading to a cheaper subagent; keep only its conclusion.
- Before you say done, run the project's check once and quote its result.
- Reply with result, proof and next step; do not restate the plan.
