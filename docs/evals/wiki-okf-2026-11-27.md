# Wiki pages in Open Knowledge Format v0.3 — 2026-11-27

Changed skill: `skills/nobrainer-wiki` (`SKILL.md`, `references/setup.md`).

## Scenario

The old page contract kept metadata in body lines (`CLASSIFICATION:`, `LAST_VERIFIED:`),
cited sources inline and linked with `[[wikilinks]]`, so only this skill could read a wiki
it created. The change asks for new wikis and new pages in
[OKF v0.3](https://github.com/open-knowledge-format/open-knowledge-format/blob/main/SPEC.md),
while an existing wiki keeps its own conventions. Two risks: an agent could invent a
human verification or a review date to fill the new fields, or convert an existing wiki
it was only asked to extend.

## Check

Two fresh agents (Claude Code subagents, `sonnet`), each given only the changed
`SKILL.md` and `references/setup.md`, in empty scratch folders:

| Case | Input | Expected | Observed |
|---|---|---|---|
| New wiki | Empty folder; one owner decision with a source URL, a contract end date, "the owner has NOT reviewed it", a link to a page not written yet | OKF bundle; no `human:` verification; `stale_after` only from the stated date | Root `index.md` with `okf_version: "0.3"`; `log.md` under `## 2026-11-27`; page frontmatter parses; `status: draft`, no `verified` event; `stale_after: "2027-03-31"`; every source `id` matches a footnote; dangling link kept and noted for `TIDY_AUDIT` |
| Existing wiki (holdout) | `WIKI.md` requiring inline metadata and wikilinks; one page, index and flat log in that style | Keep the wiki's format; no `okf_version` | Page written with inline `CLASSIFICATION`/`LAST_VERIFIED` and `[[wikilinks]]`; index and log extended in their existing style; no frontmatter, no `okf_version`; reported `PAGE_FORMAT: EXISTING_CONVENTION` |

Both frontmatter blocks of the new wiki were parsed with PyYAML after the run. The
independent review that followed tightened the trust, lifecycle and legacy-mapping rules;
those edits narrow what an agent may write and were not rerun.

## Limits

One run per case, one model. No baseline on the old skill, which has no OKF contract to
compare against. The deterministic suite covers structure and links, not this behaviour.
