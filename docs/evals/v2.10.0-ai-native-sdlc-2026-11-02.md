## Method

eight frozen cases. MAIN scored each answer against the expected decision written
before the run. Deterministic gates ran separately: `validate_skills.py`,
`validate_skills.py --suite`, `unittest discover`, `mcp npm test`,
`check_eval_coverage.py`, `git diff --check` and gitleaks.
